## 0. Ключевые отличия текущей версии (кратко)

| Область | ПЛАН | ФАКТ |
|---|---|---|
| Распределение по ядрам | `loop`/сеть — Core 0, движение — Core 1 | **так и сделано:** `supervisorTask` (FSM/Wi-Fi/USB) — Core 0, `motionTask` + ISR — Core 1 |
| Таймер шагов | 200 кГц, 5 мкс, сетка 10 мкс | **как в проекте:** 200 кГц / 5 мкс, ячейка кольца 10 мкс |
| Буфер УП | 10 000 команд × 15 байт | **2 000 команд × 27 байт**, статический массив |
| Конвейер кадров | потоковый look-ahead-буфер | **кадр за кадром, следующий — только после полного слива** |
| Soft limits | проверка `minX…maxZ` | **реализовано:** `validateMachineTarget()` до постановки кадра, с лазерной поправкой |
| Single Block | `NEXT_BLOCK` | **команды нет**, режим не продвигается |
| `START_FROM_LINE` | старт с указанной строки | **всегда стартует с кадра 0** |
| JOG | многократные перемещения | **одно перемещение**, затем блокировка в `JOGGING` |
| Шпиндель | ШИМ 0–10 В (GPIO 23) | **только реле** M3/M5 (GPIO 21) |
| Лазерная калибровка | прогон по X с замером | **движения нет**, замеры в одной точке |
| Живой контур ESP32-CAM | поправки применяются на лету | **пакет принимается и отбрасывается** |
| Аварийная остановка | ISR только обесточивает и ставит флаг | **так и сделано:** FSM/NVS/Serial — в `supervisorTask` |
| Мягкая остановка | `STOP` | **есть:** очередь сбрасывается, `isHomed` сохраняется |
| Arduino core | 2.x | **2.0.17** (`espressif32@6.12.0`), сборка проверена; для 3.x нужен порт таймера |

## Как поддерживать эту документацию

- **Один факт — одно место.** README не описывает поведение: он ссылается на `docs/`.
- **Проверка перед коммитом и в CI:** `python3 scripts/docs.py check` (таблица конфига, GPIO, структура задач, размеры) и `links` (ссылки и анкоры); `gen` — перегенерировать таблицу.
- **Список задач и ограничений живёт только в [TODO.md](TODO.md).** Здесь — ничего не дублируется.
- Номера разделов `§N.N` сохранены от прежнего монолитного README: на них ссылаются код, TODO и GUI.
