- **P2-1 · Исправить `START_FROM_LINE`.**
  `src/wifi_manager.cpp:213–221`; `src/gcode_program.cpp:217–228`.
  Обработчик находит индекс строки, но `startProgramExecution()` безусловно ставит `currentCommandIndex = 0`.
  **Действие:** передавать стартовый индекс параметром или выставлять его после сброса; синхронизировать `plannerSteps*` с фактической позицией; проверить, что предыдущие кадры не выполняются.
  **Готово, когда:** запуск с середины файла начинается с указанной строки.

- **P2-2 · Реализовать Single Block / `NEXT_BLOCK`.**
  `src/gcode_program.cpp:81–83, 125–130`; `src/wifi_manager.cpp:193–194`.
  Команды `NEXT_BLOCK` нет; после `SINGLE_BLOCK_ON` программа встаёт навсегда, а `SINGLE_BLOCK_OFF` не принимается в `RUNNING`.
  **Действие:** добавить `NEXT_BLOCK` как глобальную команду (сбрасывает `waitNextBlockTrigger` и запускает следующий кадр); разрешить `SINGLE_BLOCK_OFF` в `RUNNING`; корректно выходить из режима.
  **Готово, когда:** покадровое выполнение продвигается по команде и отключается на ходу.

- **P2-3 · Возвращать JOG в `IDLE`.**
  `src/wifi_manager.cpp:223–228`; `src/gcode_program.cpp:147–166`.
  После JOG станок остаётся в `STATE_JOGGING`; следующие `JOG`/`HOME`/`START_PROGRAM` блокируются, выйти можно только через `RESET_ALARM`/`ESTOP`.
  **Действие:** после завершения движения (`!isPlannerBusy`) переводить в `IDLE`; поддержать очередь JOG или запретить новый JOG до завершения; добавить таймаут.
  **Готово, когда:** серия JOG-команд выполняется подряд без сброса аварии.

- **P2-4 · Ограничить строковые буферы и починить Wi-Fi-парсер.**
  `src/wifi_manager.cpp:15, 79–113`; `src/main.cpp:61–76`; `src/laser_map.cpp:9–31`.
  `String`-буферы растут без предела; при `available() == 0` неполная строка обрабатывается как команда → пакеты рвутся/теряются.
  **Действие:** максимальная длина команды (например, 256/512 байт), обработка только завершённых строк, сброс при переполнении с ошибкой; для `B:` — отдельный лимит; убрать `trim()` до проверки длины.
  **Готово, когда:** медленная/рваная передача по TCP не ломает пакеты; переполнение не приводит к OOM.

- **P2-5 · Валидация и точность конфигурации.**
  `src/config.cpp:71–105`.
  `SET_CONFIG` принимает любое значение без проверки (`stepsPerMmX = 0`, `laserMapSize > 250`, отрицательный `laserGridStep`); `GET_CONFIG` печатает float с 2 знаками; bool `true/false` парсится через `toInt()` → `false`.
  **Действие:** таблица допустимых диапазонов, проверка `isfinite`, отдельный парсер bool (`true/false/0/1`), печать float с 3–4 знаками, отказ с `ERROR` без сохранения; не сохранять конфиг при ошибке.
  **Готово, когда:** некорректное значение не меняет конфиг и возвращает ошибку; `slopeY` не теряет точность.

- **P2-6 · Убрать дублирование телеметрии.**
  `src/state_manager.cpp:105–144`; `src/wifi_manager.cpp:29–35`.
  `reportStatusToPC()` печатает статус в `Serial`, затем `sendToWiFiClient()` печатает его ещё раз → в USB каждая строка дублируется.
  **Действие:** один владелец вывода: `sendToWiFiClient()` только TCP, либо `reportStatusToPC()` не печатает в `Serial`; добавить счётчик/метку времени и защиту от слишком частой отправки.
  **Готово, когда:** в USB одна строка телеметрии на интервал.

- **P2-7 · Согласовать протокол с GUI.**
  `src/scan_task.cpp`; `docs/protocol.md §6.8`, `docs/gui.md`; GUI `connection_worker.py:144`.
  Расхождения: формат скана (`X;DIAL;...` vs `SCAN:X;Z;TYPE`), единицы JOG/SCAN, отсутствие flow control при заливке, лимит 2000 кадров, семантика «СТОП».
  **Действие:** выпустить версию протокола (например, `PROTO:1`), привести формат скана и единицы к одному стандарту, добавить подтверждения/окно при заливке и проверку лимита на стороне GUI, заменить «СТОП» на `STOP`/`HOLD` с понятным поведением.
  **Готово, когда:** GUI и прошивка проходят совместный сценарий: подключение → заливка → старт → пауза → продолжение → остановка.

- **P2-8 · Убрать рекурсию M-кодов.**
  `src/gcode_program.cpp:133–143`.
  Каждый M-код вызывает `executeNextProgramStep()` рекурсивно; длинная серия `M3/M5/M8/M9` может переполнить стек.
  **Действие:** заменить рекурсию циклом/очередью: M-код выполняет действие и возвращает управление, следующий кадр берётся из `loop()`.
  **Готово, когда:** программа из 2000 M-кодов выполняется без роста стека.

- **P2-9 · Исправить разбор `G01`.**
  `src/gcode_program.cpp:149–153`.
  `line.indexOf("G0")` срабатывает на `G01`, тип остаётся 0 (G0) вместо G1.
  **Действие:** нормальный токенизатор G-кода (пробелы, регистр, десятичные), а не поиск подстроки.
  **Готово, когда:** `G0`, `G1`, `G01`, `G1.0` разбираются корректно.

- **P2-10 · Определить ёмкость буфера УП и тип номера строки.**
  `src/gcode_program.h:6–18`.
  Сейчас 2000 × 27 байт (54 КБ) и `lineNum: uint16_t` (предел 65 535); проект обещал 10 000.
  **Действие:** решить: оставить 2000 и задокументировать либо поднять до 10 000 с проверкой свободной SRAM/PSRAM; `lineNum` сделать `uint32_t` или явно ограничить файл 65 535 строками; обновить GUI и `docs/protocol.md §6.5`.
  **Готово, когда:** лимит известен, проверяется при заливке и совпадает в прошивке, GUI и документации.

- **P2-11 · Реализовать ШИМ шпинделя (когда будет железо).**
  `src/pinout.h:27`; `src/config.h:20–21`; `src/gcode_program.cpp:136`.
  Сейчас M3/M5 только включают реле GPIO 21; `SPINDLE_PWM` (GPIO 23), `pwmFrequency`, `pwmResolutionBits` не используются.
  **Действие:** LEDC-ШИМ 0–10 В, обработка `S` в M3, плавный пуск/останов, блокировка при `ALARM`, сохранение уставки; проверить уровень на VFD.
  **Готово, когда:** `M3 S...` задаёт обороты, `M5` останавливает, авария снимает сигнал.

- **P2-12 · Зафиксировать семантику WCS/наклона для JOG и сканов.**
  `src/gcode_program.cpp:100–124, 147–166`; `src/scan_task.cpp`.
  Сейчас наклон A/B применяется только к кадрам УП; JOG и `SCAN_GEOMETRY` работают без него. Это нужно либо оставить и описать, либо исправить.
  **Действие:** принять решение, добавить в `docs/geometry.md §5.2` и тест; при необходимости применять наклон/WCS единообразно во всех точках входа.
  **Готово, когда:** поведение одинаково для УП, JOG и скана или явно задокументировано как исключение.
