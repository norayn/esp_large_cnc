- **P1-7 · Валидировать карту провиса.**
  `src/motion.cpp:88–120`; `src/config.h:19`; `src/laser_map.cpp`.
  `updateCurvaturePoint()` проверяет только `index < laserMapSize`, но не границу массива 250; `SET_CONFIG:laserMapSize` может вывести за пределы; `getCorrection()` делит на `laserGridStep` без проверки; интерполяция берётся по конечной X кадра.
  **Действие:** `1 ≤ laserMapSize ≤ 250`, `laserGridStep > 0`, проверка `index` и `isfinite`; защита от `size = 0/1`; интерполяция внутри длинного кадра (или разбиение кадра) — по решению.
  **Готово, когда:** некорректный конфиг отклоняется, карта не выходит за массив, на длинном G0 нет ступеньки.

- **P1-9 · Доопределить живой контур ESP32-CAM.**
  `src/laser_map.cpp:24–31`.
  `updateLaserMapCommunication()` читает `Serial2`, разбирает `OFFSET: Y=…; Z=…`, но никуда не сохраняет.
  **Действие:** либо применять поправки к текущему кадру/следующему (с ограничением скорости изменения), либо удалить код и явно записать в `docs/geometry.md §5.3`, что живой контур не поддерживается.
  **Готово, когда:** нет «мёртвого» парсера; поведение описано и проверено.
