# 7. Взаимодействие с GUI

> Часть паспорта прошивки. Оглавление — [INDEX.md](INDEX.md).
> **Читать перед:** изменением форматов команд/ответов, синхронизацией с PyQt-клиентом.
> **Источник истины:** `src/wifi_manager.cpp` (прошивка), `norayn/large_cnc_gui` (клиент).

Репозиторий: https://github.com/norayn/large_cnc_gui (PyQt6, USB или Wi-Fi 192.168.4.1:8888).

Архитектура клиента, транспорт, разбор строк и единицы — [gui-app.md](gui-app.md) §7.1; операторские сценарии, блокировки UI и приёмка — [gui-flows.md](gui-flows.md) §7.2. Ниже — только то, что связывает прошивку и клиент.

**Известные расхождения прошивки и GUI:**

| Что | Прошивка | GUI |
|---|---|---|
| Подача JOG | читает `F` как мм/мин (P0-7) | отправляет мм/мин — согласовано |
| Скорость скана | читает `SPEED` как мм/мин (P0-7) | отправляет 500 (мм/мин) — согласовано |
| Формат скана | `X;DIAL;LASER_Y;LASER_Z` | ожидает `SCAN:X;Z;TYPE` |
| Статус | отдаёт `IDLE (LOCKED)` | показывает строку целиком; логика паузы сравнивает только `HOLD` (с ним расхождения нет) |
| Загрузка УП | максимум 2000 кадров, `ok` на каждый | шлёт всё без подтверждений, лимит не проверяет |
| «СТОП» | `STOP` — мягкая остановка, `isHomed` сохраняется; `RESET_ALARM` сбрасывает хоуминг | отправляет `RESET_ALARM`, после чего нужен повторный хоуминг |
